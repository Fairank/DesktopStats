# Desktop Stats 0.52 可选六版参考数据

本包独立于主程序，Stats默认不下载、预载或解析。没有安装、重启、提权、采集器或遥测。
固定六版：原版（无笑脸）、可爱笑脸、彩色手绘、纯线条、奶油贴纸、拼色剪纸。相同型号的结构和数量保留。

- widgets：六版CPU/GPU小组件静图与2秒单次动效，读数为合成演示。
- h5／helios：两套完整参考装机六版近景总览；各有2秒合成转速及GPU、两条独立RAM各3.36秒有限往返演示，单次播放可手动重播。H5 GPU实际38.186mm、Helios GPU与RAM52mm，52是上限而非完整取出。参考解除连接／扣具用精确临时遮罩表示。
- DesktopStats-protected-reference052.zip：原版独立模型、说明、公钥、对应receipt和许可文件；可由支持glTF2的查看器手动检视。
- desktopstats-native-six-atlas052.zip：手动打开HTML的六版静态图册，179个已有CPU/GPU/RAM身份、1074组风格源图；不是1074种产品。HTML约22MB，浏览器仍解析全数据，未测浏览器占用。

13份列出的PNG/GIF/GLB另存副本含隐藏标识，均完成owner提取与负样本检查；图册JSON/SVG无隐藏标识。RELEASE_INDEX签名仅核对确切发行字节，水印不保证不可去除，不是胜诉保证。
3D参考的两条前置I/O容量未知、未完成真实机械拆装、原生效果及本机CPU温度验收等限制仍保留。风扇动效使用合成RPM，不能冒称本机测速。
