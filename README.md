这是按需下载的原版 North XL 参考装机 GLB 资料，不是安装包，也不是当前 Stats 可以直接导入的扩展包。

保留363个原始网格、107662个三角形及独立部件节点。18个原part_id组与3个明确未标part_id的组件组分开保留；8条已知线束保留归属。无图片贴图、无外部资源，不代表本机识别或厂商CAD。

支持GLB编辑的工具可以按节点选择、移动和检查。随附唯一显卡有限插槽方向动画，约51.086mm；供电模型在演示期间暂时隐藏。播放器可能自行循环，不是实物机械拆装说明。
