可自由组合的原生 Windows 顶部状态栏与桌面监控组件。可只保留上方栏，
也可按需添加卡片、横条或竖条；悬停查看趋势，点击固定硬件详情。

**0.38.0-preview.1 · 预览版 · Windows x64 · 仅限许可规定的非商业用途**

独立的 **硬件型号图鉴**：64 款机箱、42 套散热方案、21 款电源、38 款风扇，
共 165 个条目（含 1 套自定义水冷参考组合），均有原版、可爱笑脸、彩色手绘、
纯线条等 13 套外观。保留玻璃转角、木饰板、塔体、泵头、孔栅和叶轮等系列区别；
原版保持无表情，未核实的结构明确标作参考细节，尚未覆盖全部市售产品。

本轮补充 15 款、合计 11 个品牌的电源，覆盖 ATX、SFX、SFX-L 和全模组、半模组、
固定出线。分别表现 OLED 空屏、静态 RGB 扇叶、叶端外圈、漏斗入口、开放电机支架和
白色机身；未核实的接口排列、孔栅和支架细节保持参考标记。三维检视器可查看出线类型、
规格及风扇尺寸；OLED 不借用整机或显卡功耗，未知读数继续为空。

手绘版增加长线笔触与轻微重描，图鉴使用方格纸底；原有 150 款的原版图形保持不变。
同一批代表模型的三维线条首建耗时降低约 27%–42%，临时管理堆峰值由 22.58 MiB
降至 16.59 MiB；这是显式构建线稿的成本，不是整个应用的常驻内存。没有增加后台时钟、
模型预载或硬件采样。

在 **设置 → 整机视图 → 浏览全部型号与外观** 打开二维图鉴，可按品牌或型号搜索。
图鉴只生成可见卡片，默认静止；显式开启的叶轮演示使用同一个时钟，关闭图鉴后清空缓存，
不绑定本机测速或增加硬件采集。四类 SVG 图集可从 GitHub 分别下载，
它们是独立插画文件；应用已包含这些外观，无需导入。

需要暂时保留正在运行的 Stats 时，也可下载独立 **Model-Atlas.zip**：完整解压后打开
`index.html`，即可离线查看相同的 165 个型号和 13 套外观，不需要安装或重启 Stats。
每次只载入当前类别与风格、显示最多 12 张卡片；风扇演示默认关闭，明确为非实测。
独立预览不识别本机硬件，关闭页面后不留下预览服务。

新增 **硬件扩展包**：Intel 与 AMD CPU 型号包可分别从 GitHub 下载、导入和移除。
本体保留原有 3 款 CPU，两个可选包补充 72 款，覆盖常见桌面、入门旧款与 Threadripper，
合计 75 款 CPU。它们使用 7 类共享封装，全部 13 套外观共用相同型号、形状和数量。
未核实的尺寸保留空值，采用明确标注的系列参考轮廓；不把每个同封装型号画成不同实物。
散热器扩至 42 款、风扇 38 款，包括薄型下压、异径双塔与冷排内泵等结构。

首批两个扩展包合计约 **10 KB**；程序仅保留型号索引和最多 8 个选中型号描述，
不预载整个型号库的三维模型，不增加目录轮询、传感器采集、后台线程或服务。
首版包格式支持 CPU，其他硬件现有目录继续留在本体。下载与导入方法、限制和非商用许可
见 [硬件扩展包说明](docs/HARDWARE_PACKS.md)。这是一批有来源的逐产品扩充，尚未覆盖市场所有产品。

整机装配增加具体型号的主板、风冷与水冷散热器、机箱风扇、电源、存储及扩展卡。
CPU、显卡和每条内存可以独立选择参考型号；同一机箱内可逐类、逐件混搭十三套外观。
原版保持无表情，换风格保留部件数量、尺寸、安装方向和已核结构。
参考型号不绑定另一件硬件的温度、功耗或转速，未知型号继续明确标注。
当前目录和各型号资料状态见 [可选装配清单](docs/ASSEMBLY_CATALOG.json)，未覆盖全部市售产品。

三维模型继续细化：显卡改为有真实开孔的薄壳，分别绘制散热鳍片、PCB 边缘、
接口空腔与紧固件；内存按 DIMM 与 SO-DIMM 的安装方向区分，机箱增加倒角和细网孔。
已核实的主板与十二款机箱补充原厂接口数量，其余内部排布保持明确的比例示意。
模型提供 **简洁 / 精细 / 近看细节** 三档，按需生成，实时读数和短时特效不重建模型。
十三套风格各有不同的选中动效，播放后停止刷新；详见 [模型质量与特效说明](docs/ASSEMBLY_QUALITY.md)。

桌面小组件移除右下角可见的缩放斜线，仍可从角落调整大小。默认三指标卡片按主指标与
辅助指标排列；已自定义的位置、顺序与布局继续保留，不新增后台采样。

设置新增 **整机视图**：按需打开可旋转、缩放及展开的真实三维示意，分别查看整机、
显卡、CPU、内存和主板。硬件外形复用本体 178 项目录，安装两个 CPU 包后共 250 项；机箱目录扩充至 **64 款、18 个品牌、
6 类结构**，尚未覆盖所有市售机箱。机箱型号可按品牌筛选并手动选择；自动匹配仅采用已验证的
固件标识，DIY 主机通常不提供机箱型号，不会从 ASUS 主板推断 ASUS 机箱。
当前目录还没有经过验证的零售机箱固件映射，识别不到时使用明确标注的参考机箱。
模型是原创比例示意，不是厂商 CAD 或安装兼容性保证；未知散热器、电源与机箱风扇
不按已安装部件绘制。三维视图默认静止；可选风扇动效沿用当前显卡的有效转速和既有
共同动画时钟，视图隐藏、最小化或关闭时停止，关闭后释放渲染资源。
见 [三维整机视图说明](docs/USER_GUIDE.md#三维整机视图0320-预览版)。

四套主要外观为 **原版（无表情的微型实物）、可爱笑脸、彩色手绘、纯线条**，覆盖本体及已安装包的相同硬件条目。
笑脸只属于单独的可爱外观；原版保留加笑脸前的图形，额外旧样式仍可选择。
另有 **奶油贴纸、拼色剪纸、蓝墨手账** 三套无表情的可选方案。每套都共用原版的完整型号目录：
147 个显卡、28 个内存、3 个基础 CPU（可选包再补 72 个）；仅改变插画表现，不删减硬件或改变自动识别、转速和读数。
这些数量表示当前已收录目录，后续扩充型号时，各方案同步使用更新后的目录。
按已核型号保留显卡外壳、风扇结构、CPU 封装和内存条形态，旧外观与已有选择继续保留。
图标和叶轮按需生成后复用，动效共用原有时钟，不增加硬件采样或后台服务。
CPU 温度成功恢复后同步更新启动状态；只切换图标不需要重启温度桥接。

顶部栏设置只保留一个实时预览，**内容与排列** 调整指标和顺序，**外观** 选择
整体设计、材质与连续透明度。桌面组件列表只在编辑桌面时显示；保存状态和待应用
更改在页底明确提示，原有布局、图标及版本 12 动效继续保留。

硬件详情先呈现当前读数与趋势，再按需显示 **占用最多的软件**。CPU、内存、GPU
和专用显存支持前五名排行；CPU 的逻辑处理器网格可展开，来源与限制另行查看。
顶部栏排行仅在详情及排行区域可见时采集，离开即停止，不写入历史或设置。

全屏游戏或应用位于前台时，顶部栏和详情自动避让，回到普通桌面后恢复。
设置隐藏或最小化时暂停预览动画、历史页查询和额外来源检查，保留草稿与滚动位置；
常规采样继续使用已保存的间隔，不通过缩短采样来改善视觉效果。

CPU 温度取决于机器实际提供的来源。本机 ASUS 适配使用可选的**只读会话桥接**，
需要已有 ASUS 服务及明确的管理员授权，随当前应用退出，不安装驱动或服务。
可在偏好中开启 **启动时恢复 CPU 温度**（默认关闭）：每次启动确认一次管理员授权，
全屏游戏时延后到回桌面；取消后本次会话不再提示。桥接本身不设开机启动，
不支持的机器或失效读数会显示原因。
见 [CPU 温度桥接说明](docs/USER_GUIDE.md#asus-cpu-temperature-bridge)。

### 三套顶部栏设计

[![三套顶部栏的实际深浅色对比，合成示例数据](assets/showcase/top-bar-designs.png)](assets/showcase/top-bar-designs.png)

在 **外观** 中选择经典菜单栏、分组胶囊或精密仪表，共用同一个实时预览，保留指标、组合、单位与设备设置。

可选图标动效默认关闭。开启后，CPU/GPU 的温度驱动黄橙红电弧，功耗驱动蓝白电流；短电弧在不同位置闪出、分叉、熄灭。独立温度计使用温柱和黄红热晕，不显示电流；风扇平滑旋转。强度与速度连续调节，缺测、零活动和减少动画时静止。

选择 **图标动效 → 硬件联动** 可让同一图标显示独立的硬件通道：CPU/GPU 的负载、黄红热感与蓝色功耗反馈可以同时出现，网络和电池分别处理两个方向。电弧在十个视觉阶段之间连续过渡，逐渐增加伸展幅度、放电频率和同时出现的细丝；真实数值不分档。内存没有温度传感器时不编造发热，NVMe 损耗也不会被当成负载。

## 功能

- 桌面卡片、横条、竖条；组合或独立显示，支持自适应布局、拖动排序与对齐吸附。
- 多屏顶部栏；按需选择指标、显示样式、位置和单位，悬停查看详情。
- 顶部栏以单一实时预览连接“内容与排列”和“外观”，支持三套整体设计与连续透明度。
- CPU 与 GPU 支持组合读数：同一格放入最多四项指标，整组拖排，组内可调整内容和顺序。
- CPU 详情可展开逻辑处理器使用率，关联频率、温度、功耗与风扇读数；CPU、内存、GPU、显存的 Top 5 软件排行按需采集。
- 指标行右侧直接调整或删除；组合编辑可确认或取消。图标动效按项选择，强度和速度连续可调，默认关闭，并遵循系统减少动画设置。
- 动效围绕图标局部结构呈现，保留清晰的静态轮廓；彩色细节和节奏随真实读数平滑变化，不作为告警或标定转速。详情按当前读数、真实趋势、软件排行和可展开核心明细排列。自动切换网卡或系统卷后，图表仍只显示当前设备的历史，不混入其他设备。
- 网络上下行、磁盘读写、电池充放电支持同框显示。
- 六种皮肤、连续透明度和圆角、可选标题与图表；全局默认和单组件设置独立。
- CPU、GPU、内存、电池、网络、磁盘与部分温度、功率、风扇读数。
  每项数据保留来源与不可用原因，不把缺测显示为零。
- 设置分区保存，支持撤销、导入导出、多语言及 0.01–5 秒请求采样间隔。
- 本机历史记录，支持 10 分钟、1 小时与 24 小时查看；折线保留缺测，聚合保留峰值范围。
- 日常办公、性能观察、续航场景，以及自存布局和上次布局恢复；先预览再应用。
- 来源诊断先显示原因和下一步，接口错误按需展开；支持重新检查与脱敏导出。

使用随硬件而异。普通电脑不一定提供整机输入功率或噪声传感器；本软件不从
CPU/GPU 功率推算整机功率，不从风扇转速编造分贝。更快的请求间隔不保证硬件
以同样频率返回新读数。Windows 透明效果、系统策略及显示驱动可能影响玻璃效果。

## 安装与使用

公开预览目前提供经过检查的源码快照，Windows 安装包暂未发布。

解压 Windows 发布包，保留 `DesktopStats.exe` 与 `_internal` 在同一目录，运行
`Install.cmd`。源码包不能直接当作安装包使用。托盘图标可打开设置或退出程序。
升级前先应用或撤销未保存设置，安装程序会保留可恢复的旧安装备份。

在“桌面组件”按 **＋** 添加模板；只用上方栏时可关闭全部桌面组件。已保存为仅顶部栏
的配置首次打开设置会直接进入顶部栏页。**内容与排列** 调整指标，**外观** 调整样式；
“应用”或“放弃更改”只处理当前区域。更多操作、传感器来源与限制见 [使用和开发说明](docs/USER_GUIDE.md)。

“历史记录”可独立暂停和清空，数据仅保存在本机。按来源原始时间戳记录；普通写盘
采用五秒批次门槛，两秒采样时约六秒一次，实时查询包含未提交尾部；不把重复读取的
缓存当作新的硬件样本。暂停记录或正常退出时尝试保存尾部。

的软件配置。离屏检查只能验证布局与交互，不能证明原生 Windows 磨砂效果。
源码导出按白名单包含当前快照和文件校验清单，不包含旧版本程序、私人配置或日志。

经校验的九个库，不执行下载内容；随后由本机编译原创采集器。构建需要已有的
Windows .NET Framework 编译器；脚本不会自动安装驱动或 SDK。
