# SSD 与通用电源：可单独下载的开源参考包

这两份 ZIP 可以分别下载，在 Stats 的开源模型检视中手动选择。
一次只加载一件；切换六套既有风格共用同一份只读几何。
模型没有预载、自动识别、自动装配或额外后台定时器。

| 下载 | 来源与范围 | 实际几何缓冲 |
| --- | --- | ---: |
| [Samsung 990 PRO SSD 参考包](DesktopStats-CCBY-Samsung990PRO-SSD055.zip) | 作者标题标注为 1TB；2 个源绘制／选择分区、2,038 三角面 | 146,736 字节 |
| [通用电源参考包](DesktopStats-CCBY-generic-PSU055.zip) | Groovex 通用 PSU；43 个源绘制／选择分区、12,229 三角面，不指定零售品牌、型号或功率 | 880,488 字节 |

这里的缓冲字节是单件位置与法线数据，不是整个软件的内存占用。
两份最终 ZIP 均已通过真实公共加载器检验：完整文件与 CRC、许可和来源
哈希、部件选择标识、六版共享几何、ZIP 句柄关闭及模型对象释放均通过。
软件图与原生界面效果需另行验证，不把数据加载通过当作精模或外观验收。

保留原始 GLB、索引、UV、法线、切线、编码贴图、材质描述与全部署名许可。
没有删三角面或静默修整源缺陷。当前查看器只显示原几何与颜色因子，
贴图标签、灯光和完整 PBR 尚未还原。作者源比例仅按显示方式转换；
制造尺寸、孔位和装配适配未核定，不能自动装进真实机箱或冒称本机硬件。
参考模型不绑定本机温度或真实转速，未添加动画。

内存参考暂未纳入：其 F32 坐标转换存在有效三角面塌陷和方向变化，
两种仅平移坐标起点的尝试均产生新的回归。失败数据和诊断保留，
不通过删除问题面或放宽检查把它标为完成。
