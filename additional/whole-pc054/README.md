# 完整台式机开源结构参考包

此可选包把现有开源台式机模型用于 DesktopStats 手动 3D 检视，包含 25 个逻辑部件、67 个原始绘制分区和 33,383 个三角形。支持六套既有配色，使用同一份不可变位置／法线数据。

来源：PC Components Manual，作者 mohammed rayyan hussain（mdrayyanhussain2006）。

固定来源：https://github.com/mdrayyanhussain2006/pc-components-manual/tree/1aabb3b1a537f47b2d91d83e9113cd9454013c1e

上游 README 明确声明 MIT；原文随包保存。meshoptimizer 的 MIT 许可全文另行保留。本包不向第三方 MIT 文件施加非商业限制，也没有添加我们的水印。

原始 GLB、解码后的 glTF／缓冲和材质／动画信息完整保留。运行时读取已验证的静态初始装配位置／法线；没有执行上游网页或在检视时运行解码器。源世界姿态米转换为显示毫米，不代表制造校准。

包含 CPU、CPU 散热器、显卡、主板、4 条内存、3 个机箱风扇、电源、M.2、存储、机箱和独立侧板，以及电缆／接头。六版预览仅隐藏独立侧板以便观察；可下载模型保持所有部件。

这是通用教学参考，不是品牌／系列全覆盖；不对应本机识别结果。当前仅静态检视，不宣称真实 RPM、拆装动画、自动物理兼容、完整 PBR／透射或原生渲染实测。

外观验收仍未完成：纯线条的 CPU／机箱风扇叶片轮廓缺失较多；原版为深色通用参考。六版配色可用不代表六套外观细节全部验收。
