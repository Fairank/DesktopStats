# 通用风扇与独立冷排 · 开源参考资料

两个独立下载包来自 [PC Anatomy](https://github.com/Yoosseph/pc-anatomy/tree/9ca9c9635a19abd189cd9978396d26be7a5d0858)，作者 Yoseph。它们是通用教学部件，不是新增的已核零售硬件型号。

- [风扇参考包](DesktopStats-open-fan-reference053.zip)：框架与叶轮可分别检视，九片叶片共享几何；含原始独立导出和绕序／法线修订版两份 GLB，以及来源、检查说明和完整 MIT 署名。
- [冷排参考包](DesktopStats-open-radiator-reference053.zip)：独立冷排子组，含两端水室、11 条流道、58 层共享鳍片、背片与文字材质。它采用 JSON／BIN／PNG／RGBA 参考数据格式，包含完整许可；不含风扇、接头、泵或管路，也不是标准 GLB。

文件大小及 SHA256 见 [PACKAGES053.json](PACKAGES053.json)。摘要只能核对下载字节；实际远端提交与读回记录另行保留，摘要本身不证明上传成功。

两包均不是 Stats 的 `.dspack`，当前不能直接导入或作为已安装部件使用。有限软件预览只帮助看清部件；原生六版绘制、真实安装尺寸、孔位、完整水冷装配与实测转速尚未验收。风扇原框架的四个极小三角面仍保留，整体模型质量没有被宣称全部通过。
