# 六套既有风格的公共线条预览

本目录只有两张静态预览与来源说明，没有新增模型 ZIP。既有模型包、全部源几何和此前 32 个数据路径保持不变。

完整台式机来源：PC Components Manual，mohammed rayyan hussain（mdrayyanhussain2006），上游 README 声明 MIT；meshoptimizer 为 MIT。原始许可声明与来源仍在既有整机模型包中。

https://github.com/mdrayyanhussain2006/pc-components-manual/tree/1aabb3b1a537f47b2d91d83e9113cd9454013c1e

`whole-pc-six-canonical054.png` 使用当前公共 `edge_batches` 线条规则，统一真实源模型、配色、相机、遮挡和侧板隐藏方式。原版没有边线，直接复用原帧；纯线条复用已验收新帧，仅为排版缩小；仅可爱笑脸、彩色手绘、奶油贴纸、拼色剪纸四版重新计算公共线条并生成 CPU 软件预览。

`whole-pc-face-crease054.png` 是已验收对照图的逐字节副本。此次有限修正仅涉及四个源文件证明使用 MAT_FAN_PLASTIC 的风扇绘制分区：纯线条按真实三角面法向夹角提取折线，源位置和渲染法线不变，不添加伪造轮廓，也不提高每网格 512／整景 8192 段预算。CPU 中心轮廓保留，后置风扇外框较清晰；不表示所有叶片绘画细节已完善。

首版六图采用每网格自定义 96 段预览，低估了公共纯线条规则的风扇细节。本目录是对真实公共线条规则的进一步展示，旧文件保留作为历史记录。

这仍是通用教学参考的静态因子着色，不是原生窗口截图或完整 PBR。原生效果与软件占用尚待验证；没有真实转速、动画、厂家系列全覆盖或六套精细外观全部完成的声明。CPU 风扇叶片和整体外观还需打磨。第三方 MIT 模型不附加本项目非商业限制或我们的所有权水印。
