# 三维模型的细节与运行方式

本次打磨优先修正结构，再改善材质与动效。模型属于项目原创比例示意，
不是厂商 CAD、PCB 电路图或装机兼容性验证。已核实的外尺寸、接口数量、
风扇叶片资料与参考排布分别记录，不能把多边形数量当成还原度证明。

## 0.48 主要配件、可见性与实际轮廓

本轮先复核用户指出的整机问题：旧图确为零条内存、电源被罩体遮住、灯区为空，水冷软管还存在端部缺段。风冷／AIO／分体参考现明确主要型号、两条匹配 RAM、电源、SSD 与已知线缆；未知本机仍保持未知。内部检视只改变绘制与拾取，不删除物理部件或安装检查，正常外形保留。

拥挤纯线条曾挤掉第二条 RAM 与电源外框，不能用“同数量”代替逐图验收。本轮优先保留主要硬件完整外轮廓，再分配格栅、重复板载装饰和未知内部叶轮，继续沿用既有8192边上限。AIO 双端连接、边线连通、完整主要配件和六版图片分别核对，范围与未完成项见[逐件复核](ASSEMBLY_COMPLETENESS048.md)及[本轮验证](QUALITY048.md)。

灯区仍为有限静态预览：GPU 本体、主板装饰灯、LOKI 电源及独立冷头图库控件等链路仍有缺项。AIO／分体参考的前置 I/O 尚无锚点；不能把8条已知线路零省略称为全部接齐。安装版温度、磨砂、游戏隐藏和整款资源仍待原生验收。

## 0.47 增量与验收边界（历史范围）

当前目录为 **828 个具名产品＝514 本体＋314 可选**；可选部分为 72 CPU、167 冷却和 75 水路。本体另有一套不计作产品的参考组合。各型号共享既有六版与13个保存值，原版无脸，不新增风格。

75 条水路包含原0.46的63条及新增12条GPU冷头，后者来自3品牌，通过4个新增替代数据包提供；原15个水路包保留，合计19个有重叠的替代选择包。新增GPU冷头只有独立外观检视：厂商名单、端子、背板和已观察接口分别记录，缺精确PCB接触面、安装孔与姿态时不替换整卡，也不连接水路。见[GPU冷头范围](GPU_BLOCKS047.md)和[新包索引](GPU_BLOCK_PACKS047_INDEX.json)。

六款旧主板补上来源观察的PCB、装甲、静态饰条和材质层次，当前28板均有照片观察状态；隐藏叶轮、深度、扣具、电路与全细节仍未因此核实。六款材质角色只作用于对应型号，原版颜色与线条版保留，其余22板的数据、板件物理载荷及六版颜色沿用旧校验。ASUS透明I/O饰片按精确型号与盖板名称限制，未知风扇没有变成转动齿轮。范围和六版实图见[六板说明](MOTHERBOARD_FINISH047.md)。

CPU／GPU模型小组件最小化后暂停快照更新，恢复时读取当前状态；全局硬件采样另有既有生命周期，不由这一项推断停止。图库制图改为有界按需异步任务，作用是减少界面阻塞，不能写成已测得整款CPU或RAM下降。本轮尚未安装新版，CPU温度重启恢复、三处真实磨砂、屏幕二／游戏隐藏及本机整体占用仍待原生验收。

## 0.46 独立水路与逐款图鉴（历史范围）

新增63条零售参考通过15个集合／类别／品牌替代数据包提供。10冷头、8泵／电机／泵盖、4纯水箱、10泵箱、20接头与11管材分开选择，未知口位、整体尺寸和传感器保持未知。32款冷头／泵／水箱的576张六版三视已完整重画，31款接头／管材有实际几何图鉴，见[README预览](../README.md)。它们是原创参考网格，不能把绘图包络当作厂家机械尺寸。

CPU冷头保留安装耳、金属或透明盖、侧口或顶口和空白LCD；裸泵没有虚构顶盖／螺纹口，无泵产品没有电机。弯头在套筒后端接合，管口真实开口；滚花贴在实际多边形表面，不再浮在理想圆外。RGB只使用已观察灯区；泵没有绑定独立读数时保持静止。

纯线条的圆筒轮廓采用相邻面法线与当前视角判定，沿用现有24字节顶点格式，不增加每帧CPU网格重建。单网格512与场景8192线段预算不变。复杂整机还要逐部件检查预算公平性，不能以单品预览正常代替整机场景复核。

0.46补核新增目录中的五款finish，当时28板中22款照片观察、6款旧板待完成；0.47六板增量见上节。MSI仅绘制无叶片风扇槽，ASUS仅已见网罩，内部叶片与测速未造。六版编号与13个旧保存值保持一致，未新增风格。

0.46水路是有界静态参考装配，不每帧求路。指定HAF700EVO和5000D配置三段连管可生成，曲线、自交、管间距及后加辅助部件仍分别核对，不是全机箱／全硬件的现实安装保证。当时零售GPU冷头目录尚缺；0.47已增加独立模型，但精确安装及连管依旧未接入。硬管inline弯头、任意连接图、扁平纯水箱与流体模拟仍缺。相关字段与限制见[水路说明](LOOP_COMPONENTS046.md)和[缺口清单](LIQUID_COMPONENT_GAPS.md)。

0.46选择器由六次索引处理合为一次，隔离热调用CPU中位约减少81%；共用八条已选记录缓存，图库共用既有十六条SVG缓存，未新增时钟或采集器。数值范围见[局部测量](SCOPED_PERFORMANCE046.json)，不代表整款Stats的CPU、RAM或GPU占用，也不代表0.47异步图库的降幅。该轮软件证据未完成安装版温度、磨砂或桌面验收。

## 0.45 结构、目录与低占用（历史范围）

六套固定展示及全部十三个保存选项保留；现有类别／型号补齐之前不新增外观。新增 12 主板为 ITX、mATX、ATX 各四，分别核布局而非统一缩放。AM4 使用 PGA 塑料插座与锁杆；DVI 的 24 接点和扁键、ITX 成对 SATA 有独立实际空腔。旧 16 主板×三档几何保持一致；5 款新增板的装甲照片、2 款板载微型风扇位置仍待核。

新增 40 风扇、23 散热器和 104 冷排作为 32 个按类／品牌替代数据包，未下载时不加载作者目录。单中扇双塔、下置 C 形及薄型下压采用不同安装结构；三款 Corsair LCD 的圆屏／方底座、NZXT X42 镜面与 H60 白色固定标记分别绘制，不伪造屏幕数据。SVG 和 3D 共享已设置的定性叶型；11 款新增风扇叶数未核，不能称全部还原。剪纸版叶片保留细切边，用实际旋转角度的光栅变化检验可见性。

独立冷排合计 128 款，包含 120、140、240、280、360、420、480、560 等级；AIO 覆盖 120 至 420。新增 XSPC 的六款孔距来自对应机械图；旧两款 Aqua 冷排修正孔缘遮挡，其余 22 款旧冷排×三档几何保持一致。孔口、扇位和外包络的未核部分继续明确为参考。

新增包共用最多八条已选记录缓存，不持有网格。三集合索引＋体积最大的八条已选记录对象图为 244,906 字节（只计 Python 对象，不是整机内存）；删除重复完整清单后，同记录保留对象少 15,936 字节。命中缓存的 40 次读取无读盘／目录扫描。原装风扇描述复用，减少另包读取。没有新增后台工作或传感器／动效时钟。

详细类别缺口见 [PCBS 对照](PCBS_GAP_ANALYSIS.md)，尺寸见 [矩阵](SIZE_COVERAGE.json)，完整需求见 README。占用测量边界见 [记录](SCOPED_PERFORMANCE045.json)。当前未安装、未重启，软件离屏证据不能当成真实桌面的温度、磨砂、全屏隐藏或 GPU 验收。

## 0.44 独立冷排与风扇

24款冷排有独立来源与外包络，不附带已安装风扇的推断。主／第二冷排、扇型、单面／夹心／无扇布局分开；每把风扇可独立点选／换风格。
仅已观察到的口才建模；未知口不强装AIO通用接头，也不绘制对应猜测管路。端箱、孔口和轨道都做实际几何开孔；鳍片、管数、微小厚度为有限采样参考。
空闲与隐藏状态没有增加采样、定时器或灯控。详细网格按选择建立并复用，风格切换不重建物理数组。
水箱／泵／冷排／独立冷排风扇不借用CPU温度或CPU_FAN测速；未绑独立通道时显示未知。
本轮完整需求及缺项见 [README验收总表](../README.md#全文需求逐项核对与未完成清单)，不能把这一轮作为全部完成。

## 0.43 保留的实质细化

六套固定展示和完整目录口径见 [覆盖与差距](HARDWARE_COVERAGE.md)。主板触点及 M.2 接收槽共享
所有风格的同一物理数组；参考整机 +1 mesh / +624 三角形，原安装锚点与其它几何完全一致。
这约 0.587% 的几何增加不是空闲 CPU 占用的增加比例；模型只按需构建，运行读数不重建。

灯区预览只调整已有灯区的静态色彩，纯线条处理对应轮廓线；固定白灯仍为白光。
没有新增灯、动画时钟、真实灯控或灯光轮询，换色复用物理模型。

24 个新增存储产品使目录达到 29 个。原厂散热壳独立于参考 IC，机械硬盘封盖不透明；
具体产品名及容量由所选记录提供。M.2 根据已核长度分配槽位；这不能证明电气兼容或散热片间隙。

## 0.36 按需型号与 CPU 封装

本体的 3 款 CPU 保留；新增 72 款分为 Intel、AMD 两个可选数据包，安装后合计 75 款。

同一封装内的型号共用机械外形，分别显示型号；原版保持无表情。
42 款已找到官方数值外尺寸，33 款仍使用明确标注的封装系列参考轮廓，不能称为尺寸已核。
触点为有限数量的密度示意，盖板厚度和内部布局未核；均不冒充电气针脚或制造图。

两个 CPU 扩展包共 10,084 字节；独立 Python 模块实测的型号索引及最多八个记录合计约
0.10 MiB，暂时分配峰值约 1.8 MiB。测试涵盖首次加载成本，不导入整个作者 CPU 目录。
空闲五秒未测到此模块的 CPU 时间增量；这不是整款 Qt 软件或三维视图的驻留占用结论。
包系统没有线程、计时器、联网下载或定期扫描；三维资源仍只跟随当前场景生成，关闭后释放。
具体使用与边界见 [硬件扩展包](HARDWARE_PACKS.md)，下载文件及校验见 [包清单](HARDWARE_PACKS_INDEX.json)。

手绘结构线保留真实表面坐标，在视图平面产生少量线条变化，修复线条穿进表面后断续的问题。
深度测试保持开启，背面的 CPU 触点和被盖板遮住的部件不会变成透视线；仍使用单一缓冲、
最多 8,192 段线和原有短时动效时钟。
