# 三维模型的细节与运行方式

本次打磨优先修正结构，再改善材质与动效。模型属于项目原创比例示意，
不是厂商 CAD、PCB 电路图或装机兼容性验证。已核实的外尺寸、接口数量、
风扇叶片资料与参考排布分别记录，不能把多边形数量当成还原度证明。

## 0.36 按需型号与 CPU 封装

本体的 3 款 CPU 保留；新增 72 款分为 Intel、AMD 两个可选数据包，安装后合计 75 款。
共享 7 类封装的真实形状区别，分别表现矩形、方形、AM5 缺口和工作站长形封装。
同一封装内的型号共用机械外形，分别显示型号；原版保持无表情。
42 款已找到官方数值外尺寸，33 款仍使用明确标注的封装系列参考轮廓，不能称为尺寸已核。
触点为有限数量的密度示意，盖板厚度和内部布局未核；均不冒充电气针脚或制造图。

两个 CPU 扩展包共 10,084 字节；独立 Python 模块实测的型号索引及最多八个记录合计约
0.10 MiB，暂时分配峰值约 1.8 MiB。测试涵盖首次加载成本，不导入整个作者 CPU 目录。
空闲五秒未测到此模块的 CPU 时间增量；这不是整款 Qt 软件或三维视图的驻留占用结论。
包系统没有线程、计时器、联网下载或定期扫描；三维资源仍只跟随当前场景生成，关闭后释放。
具体使用与边界见 [硬件扩展包](HARDWARE_PACKS.md)，下载文件及校验见 [包清单](HARDWARE_PACKS_INDEX.json)。

手绘结构线保留真实表面坐标，在视图平面产生少量线条变化，修复线条穿进表面后断续的问题。
深度测试保持开启，背面的 CPU 触点和被盖板遮住的部件不会变成透视线；仍使用单一缓冲、
最多 8,192 段线和原有短时动效时钟。

## 当前装配目录与混搭

当前可选目录包含 147 款显卡、28 款内存、3 款 CPU、64 款机箱、16 款主板、
42 款散热方案、38 款风扇、6 款电源、5 款存储设备及 3 款扩展卡。
其中分体水冷为原创参考组合，其余为具名产品记录；并非全部市场或每个品牌全系列。
完整条目、品牌、系列、官方资料与未核事项见 [装配清单](ASSEMBLY_CATALOG.json)。
运行 `python tools/export_assembly_catalog.py --check` 可检查清单是否与可选目录一致。

每一件配件可以继承整机外观，也可按类别或单件选择十三套风格；单件设置优先。
切换风格保留同一份物理网格、型号、数量与转轴。原版没有笑脸；仅可爱笑脸与
笑脸手绘允许机箱表情。混搭仍共用一个静态图形缓冲和最多 8,192 段结构线。
结构线优先保留机箱梁、外壳、PCB 和风扇的主要轮廓，再分配到插槽和叶片；
纯线条模式减少引脚、SMD 与细网孔的描线，避免微细节挤掉整机外形。

参考 CPU、显卡和内存可以独立更换，不修改顶部栏或检测结果；这些参考替换模型
不借用本机另一件硬件的实时读数或 RPM。手动选择未知散热器、电源和机箱风扇前，
系统不会把安装支持位置当成已经装上的配件。风冷、一体水冷与 CPU/GPU 分体水冷
提供明确的参考装机按钮，应用偏好后保存。

主板按官方手册布局分别绘制插槽、接口、固定孔和已核实的散热盖板。外观照片无法
核实的型号在选择器标注“外观待核实”，保留参考布局。小元件位置、铜箔走线、
内部封装和未给出原厂尺寸的机械细节保持示意，不将手册比例换算当作原厂 CAD。

散热器包含风冷鳍片与热管、一体水冷冷排与泵头、原创分体水冷管路；机箱风扇保留
独立外框、叶片、支撑与线缆接口。CPU_FAN 是已有代表通道，只有明确对应的已核
风冷叶轮才使用该读数；水泵转速不能驱动冷排风扇。未绑定机箱风扇与电源测速时，
实测模式保持静止。手动开启“参考转动”才使用明确标注的演示速度。

显卡外壳使用真实开孔与薄壁结构，保留叶片的可见空间；散热鳍片、PCB 边缘、
分段金手指、视频接口空腔和紧固件分别构建。有来源确认的背板才显示背板。
鳍片间距、PCB 层边和螺钉排布属于机械示意，不声称与零售 PCB 一一对应。

ASUS ROG Astral 5090 的第四把背面风扇依据
[ASUS 官方背面产品图](https://dlcdnwebimgs.asus.com/gain/71E25C26-172B-4B3B-BF80-9CD8FCAB3DA6/w1000/h732)
补充七片叶片与背板开孔。位置按照片比例示意，不标成原厂毫米坐标；转向与独立
测速尚未核实，因此背面风扇保持静止，正面三把继续使用已有转速与已核转向。

DIMM 按垂直主板的姿态安装，SO-DIMM 使用其参考安装方式。主板保留芯片封装、
插槽、VRM 与 M.2 散热器的层次；已收录主板分别采用各自手册核实的插槽数量与布局。
例如 ASUS ROG STRIX Z790-A GAMING WIFI D4 保留四条 DIMM、四个 M.2、深色 PCB
和银色散热器。其布局仍为原创比例排布。[ASUS 规格](https://rog.asus.com/motherboards/rog-strix/rog-strix-z790-a-gaming-wifi-d4-model/spec/)
与 [外观说明](https://rog.asus.com/motherboards/rog-strix/rog-strix-z790-a-gaming-wifi-d4-model/)。

机箱增加真实倒角、细网孔、折边和接口内腔。十二款已核机箱使用各自的原厂
USB 与音频接口数量和面板位置，间距仍属示意；其余型号不补造未知接口。
逐款来源保存在 `chassis_detail_catalog.py`。原有 64 款机箱及全部 178 项硬件
目录继续共享十三套风格；这不是全部市售硬件的完整覆盖声明。

## 按需细节

| 模型细节 | 使用方式 | 整场三角形上限 |
| --- | --- | ---: |
| 简洁 | 保留基础示意，降低小网孔与圆弧采样 | 80,000 |
| 精细 | 默认，包含完整参考装配的薄壳、鳍片与接口 | 160,000 |
| 近看细节 | 查看局部时增加圆弧、鳍片与触点采样 | 300,000 |

上限包含新增的完整装配，不代表每个场景实际达到上限。只有型号、装配、风格或
细节切换才重新生成静态模型；
读数更新、选中高亮和特效播放复用已有网格与图形缓冲。金属、玻璃与木饰使用
同一原生绘制流程，不增加模型下载、浏览器引擎、后期模糊缓冲或持续环境动画。

## 十三种短时特效

在三维窗口选中部件时播放，也可点击 **预览特效**。下列效果只改变表面表现，
不会变形部件或改变点击区域；原版仍然没有笑脸。

| 外观 | 选中效果 |
| --- | --- |
| 原版 | 斜向金属掠光 |
| 可爱笑脸 | 两次柔和轮廓脉冲 |
| 彩色手绘 | 彩铅色块逐次浮现 |
| 纯线条 | 笔尖方向的描线前沿 |
| 奶油贴纸 | 贴纸压印扩散环 |
| 拼色剪纸 | 分段纸片光带 |
| 蓝墨手账 | 墨色由中心扩散 |
| 经典通用 | 竖向扫描线 |
| 结构线稿 | 沿边移动的虚线 |
| 精简实物 | 硬边金属折光 |
| 柔和双色 | 羽化高光 |
| 手绘线稿 | 交叉排线显现 |
| 笑脸手绘 | 双重墨印圆环 |

每次持续 400–850 毫秒，完成后退出既有共享动画时钟。关闭 **风格特效**、
关闭动效、隐藏、最小化或关闭窗口时停止，不在恢复后自行循环。
没有有效 RPM 时选中特效仍可独立结束；风扇不会因此虚构转速。

风扇转动是单独的可选设置，使用既有所选显卡的新鲜有效 RPM，以 1/120 速度
便于观察，零转速、失效读数或未知叶片结构保持静止。驱动的板卡汇总通道不等于
每把物理风扇都有独立测速。视图关闭时释放图形资源，不增加后台传感器轮询。

## 验收方式

四类独立二维图鉴覆盖当前 64 款机箱、42 套散热方案、21 款电源和
38 款风扇，全部 13 套外观，共 2,145 张 SVG。它们是原创比例插画，来源未核实的
外观细节保持参考标记；自定义水冷为组合参考，不计作独立零售产品。
图鉴仅按可见卡片生成，最多缓存 16 份图形，关闭即清空；独立 SVG 图集不是三维扩展包。
叶轮演示默认关闭，只改变保留图层的变换，不重新生成图形，不绑定真实传感器。

三维手绘与线条采用连通轮廓预算，优先保留完整叶片、hub、角垫和分布均匀的孔栅。
共面 T 接缝先合并边界再预算，不通过关闭深度或增加实体三角形来补线，
保留全场景 8,192 条线段上限与单个保留缓冲区。

0.38 在每次构建内复用坐标、法线和连接点遍历，删除重复量化扫描及无用临时分配；
不保留跨模型缓存。原有 150 个型号的线段坐标保持一致，原生像素配对检查也相同。
八个代表模型的三次配对中位首建降低约 27%–42%，临时管理堆峰值由 22.575 MiB
降至 16.587 MiB，不含输入实体几何，也不代表整个应用的常驻内存。

电源新增固定出线、半模组、空白 OLED、叶端外圈、静态 RGB、漏斗入口及开放电机支架。
已核型号外尺寸及风扇尺寸来自厂商；孔栅密度、接口位置、支架计数和轮廓仍是原创参考，
不当成工程图或本机检测结果。固定线在已有末端接续；线束单独保留窄范围碰撞，
不会把整个电源包围盒扩大后误挡相邻模组插头，也不忽略电源实体来强行穿线。

现有 178 项硬件都经过真实外形配置构建，再分别检查三档精度；机箱另按
64 款 × 13 套风格检查。风扇开孔检查同时覆盖正面与已核背面；视频接口检查
中心和边缘，要求首先命中内部凹槽，空白区域或被盖板遮挡都算失败。
已核的侧面开放区域也要求真正能看到鳍片。

材质和结构对比采用不可变的 0.33 源码快照、同一合成配置和相同镜头。
内存修正安装方向后，保留原镜头对照，同时提供适合新姿态的检视镜头。
渲染计时只代表指定分辨率下的隐藏测试画面，不代表游戏性能或后台占用。
日常占用另在三维窗口关闭时测量应用与温度桥接子进程。

特效检查要求结束后的画面与静态画面一致、点击结果一致、不增加几何上传。
实际窗口还检查静止时停止绘制、隐藏和关闭后停止共享时钟。所有检查使用
原创模型与合成配置，不以截图中的数值冒充本机读数。
