# 三维模型的细节与运行方式

本次打磨优先修正结构，再改善材质与动效。模型属于项目原创比例示意，
不是厂商 CAD、PCB 电路图或装机兼容性验证。已核实的外尺寸、接口数量、
风扇叶片资料与参考排布分别记录，不能把多边形数量当成还原度证明。

显卡外壳使用真实开孔与薄壁结构，保留叶片的可见空间；散热鳍片、PCB 边缘、
分段金手指、视频接口空腔和紧固件分别构建。有来源确认的背板才显示背板。
鳍片间距、PCB 层边和螺钉排布属于机械示意，不声称与零售 PCB 一一对应。

逐款来源保存在 `chassis_detail_catalog.py`。原有 64 款机箱及全部 178 项硬件
目录继续共享十三套风格；这不是全部市售硬件的完整覆盖声明。

## 按需细节

| 模型细节 | 使用方式 | 整场三角形上限 |
| --- | --- | ---: |
| 简洁 | 保留基础示意，适合较低图形负担 | 30,000 |
| 精细 | 默认，增加薄壳、鳍片、接口与倒角 | 40,000 |
| 近看细节 | 查看局部时增加圆弧、鳍片与触点采样 | 80,000 |

上限是模型生成约束，不代表每个场景实际达到上限。细节切换才重新生成模型；
读数更新、选中高亮和特效播放复用已有网格与图形缓冲。金属、玻璃与木饰使用
同一原生绘制流程，不增加模型下载、浏览器引擎、后期模糊缓冲或持续环境动画。

## 十三种短时特效

在三维窗口选中部件时播放，也可点击 **预览特效**。下列效果只改变表面表现，
不会变形部件或改变点击区域；原版仍然没有笑脸。

| 外观 | 选中效果 |
| --- | --- |
| 原版 | 斜向金属掠光 |
| 可爱笑脸 | 两次柔和轮廓脉冲 |
| 彩色手绘 | 彩铅色块逐次浮现 |
| 纯线条 | 笔尖方向的描线前沿 |
| 奶油贴纸 | 贴纸压印扩散环 |
| 拼色剪纸 | 分段纸片光带 |
| 蓝墨手账 | 墨色由中心扩散 |
| 经典通用 | 竖向扫描线 |
| 结构线稿 | 沿边移动的虚线 |
| 精简实物 | 硬边金属折光 |
| 柔和双色 | 羽化高光 |
| 手绘线稿 | 交叉排线显现 |
| 笑脸手绘 | 双重墨印圆环 |

每次持续 400–850 毫秒，完成后退出既有共享动画时钟。关闭 **风格特效**、
关闭动效、隐藏、最小化或关闭窗口时停止，不在恢复后自行循环。
没有有效 RPM 时选中特效仍可独立结束；风扇不会因此虚构转速。

风扇转动是单独的可选设置，使用既有所选显卡的新鲜有效 RPM，以 1/120 速度
便于观察，零转速、失效读数或未知叶片结构保持静止。驱动的板卡汇总通道不等于
每把物理风扇都有独立测速。视图关闭时释放图形资源，不增加后台传感器轮询。

## 验收方式

现有 178 项硬件都经过真实外形配置构建，再分别检查三档精度；机箱另按
64 款 × 13 套风格检查。风扇开孔检查同时覆盖正面与已核背面；视频接口检查
中心和边缘，要求首先命中内部凹槽，空白区域或被盖板遮挡都算失败。
已核的侧面开放区域也要求真正能看到鳍片。

材质和结构对比采用不可变的 0.33 源码快照、同一合成配置和相同镜头。
内存修正安装方向后，保留原镜头对照，同时提供适合新姿态的检视镜头。
渲染计时只代表指定分辨率下的隐藏测试画面，不代表游戏性能或后台占用。
日常占用另在三维窗口关闭时测量应用与温度桥接子进程。

特效检查要求结束后的画面与静态画面一致、点击结果一致、不增加几何上传。
实际窗口还检查静止时停止绘制、隐藏和关闭后停止共享时钟。所有检查使用
原创模型与合成配置，不以截图中的数值冒充本机读数。
