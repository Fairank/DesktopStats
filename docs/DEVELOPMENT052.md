## 固定六版与型号一致性

1. 原版：微型实物，无笑脸。
2. 可爱笑脸：可爱配色和独立表情。
3. 彩色手绘：方格纸与不齐的彩色线条。
4. 纯线条：留白、手绘轮廓和真实遮挡。
5. 奶油贴纸：浅色、克制描边。
6. 拼色剪纸：清楚的色块、层次与剪纸边。

六版必须保留同型号的外形、风扇数量与形状、接口和独立部件身份。不能把未知转速设成真实转动；演示转动必须标注。CPU／GPU 小组件优先，整机可选边框、电源仓展示与各部件选取继续保留。13 个旧保存选项保留，不能拿历史样式代替上述六版验收。

## 继续工作的顺序与验收边界

先完成 CPU／GPU 六版小组件、真实叶轮和逐型号可见细节，再把机箱中的独立部件逐项接入选取、状态和有限拆装。每项检查几何、遮挡、线稿、点选、风格切换及动画结束后的停表；不每帧重建模型、不增加硬件采样器、不在后台轮询碰撞。新资源按需加载，关闭检视后释放引用。

仍须继续：剩余 GPU 待核型号、全品牌／系列的散热器与独立冷排／风扇、120／140／240／280／360 等规格、ITX／mATX／ATX 主板、内存／电源／存储／灯光、准确连接依赖、真正的扣具和线缆拆装、逐机箱兼容及可选拓展包。目录里有产品名字、能生成模型、某个代表装机通过，均不能等同于这些要求全部完成。与装机模拟器的差距继续记录在 [对照记录](PCBS_GAP_ANALYSIS.md) 和 [完整需求账本](REQUIREMENTS.json)。

逐机箱专项记录在 [机箱结构问题与来源](CASE_ASSEMBLY_ISSUES052.md)：早期从最初12款扩大到34款确切结构工厂，仍不是全部96款通过。新增17款后舱各选一套主要硬件齐全的风冷参考，102项公共主机检查已分阶段通过；后墙18款独立白名单仍不等于整机验收。历史底扇55组检查零正证据、3组材料范围缺口保留；后续MOD5全部材料复核与9项修正另列，C700M的120／140独立底架仍未完成，不把局部修正回填为全表兼容通过。公共装机链保留准确CPU／GPU／内存／电源身份，再检查罩板、底架、风扇框／插头和电源世界坐标；不能只看风扇或一张图片。内存整条高度、PCB高度、总厚度和已核公差分别保存，未知部分保持参考，不拉伸PCB来凑整条高度。
