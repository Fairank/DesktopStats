# 下一轮开发记录

更新日期：2026-11-10。这里记录开发源码与独立实验的真实进度；尚未制作新安装包，也没有重启、替换或安装本机正在使用的 Stats。

## 保持的产品规则

- 六版固定为：原版（无笑脸）、可爱笑脸、彩色手绘、纯线条、奶油贴纸、拼色剪纸；13 个历史保存选项保留。
- 同一型号在六版中共用物理形体、部件数量、接口、安装点和风扇轴。更换画法不能更换硬件。
- 主板、CPU、内存、显卡、电源、风扇和冷排采用对应型号的固定安装位。自由 XYZ 编辑已取消；未核安装位继续列为缺项。
- CPU／GPU 小组件优先。原来的顶部栏、屏幕二偏好、游戏隐藏、历史曲线与可选组件边框继续保留。
- 游戏期间只进行有界后台检查；不启动桌面测试窗口，不弹管理员授权，不读取真实传感器，不重启软件。
