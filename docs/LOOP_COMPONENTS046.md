## 选择与参考装配

1. 从[实际可选包索引](LOOP_PACKS_INDEX.json)下载并导入所需 dspack。集合、类别、品牌包是重叠替代分组，同一型号不能重复安装；字节数和 SHA256 来自实际文件。
2. 在装机设置选自定义回路，打开“自定义水冷部件”里的“按部件组水冷”。CPU 冷头、泵／电机、泵盖、水箱或泵箱组合分别选型；冷排及两面风扇继续独立选择。
3. 选默认接头和管材，也可展开接口逐口覆盖。通用连接口不假定进出方向；补液、排液、辅助和封闭口不被默认当作循环端口。
4. “参考连管”只生成有界静态路线。缺件、螺纹／公母／管径不符、未知接合或边界失败保留提示并省略连管，不以半条管冒充接通。

电机本体必须配来源支持的泵盖或泵箱；组合不能重复电机。AIO 原厂封闭冷排保护保留，新增零售部件不授权现实拆改封闭 AIO。

当前仍是固定3／4节点循环，不支持inline硬管弯头或任意编辑连接图。软管避障只在构建时搜索有限参考平面（最多12个轴向平面、2048个访问节点、160个路线点），不每帧求路。HAF700EVO和5000D的指定Astral5090／Core1／XD5／XR5360配置可生成3条路线；O11／Y70空间不足仍为clearance review，不强缩硬件。它们是指定参考配置的软件检查，不是全机箱、全装配或实物安装保证。

辅助实体采用两阶段单次构建：先提供逐件电源／存储／扩展卡的实际参考包络供水路占位，再使用同一批实体完成更新后的线缆。原先5000D双机械硬盘会与XD5／接头重叠的组合，改为避开实体或明确review、停止连管；部分加装HDD的配置因此不再被错误显示为可连通。包络检查是保守参考，不覆盖孔径、公差或完整CAD碰撞。

## 接口、长度与未知

- **G1/4 是管螺纹标准，不是管材外径。** 每端分别记录螺纹、公母或未知，再记录管材类型和内外径；逐端事实优先于摘要。
- Alphacool 17590 的官方标题／正文与技术表对公母端描述冲突，两个端保持 unknown，不能自动接合。
- Thermaltake 双管端 90° 接头两端都是 16mm 硬管口，没有外露 G1/4，不能作为默认“零件母口→管材”接头。堵头应封闭。
- 管材 length_mm 是每根供货长度，图中仅80mm样段。无官方最小弯曲半径时保留未知；CFRP不作为可热弯塑料，曲线也不证明真实管材能安全弯到该半径。
- 所有端口位置／朝向、螺纹外观、滚花／编织采样和路线为原创参考，不是厂商 CAD、实物齿数或毫米安装坐标。ports_geometry_complete只表示观察端清单齐全。
- 水温、流量、泵 RPM、液位不从 CPU 温度、CPU_FAN 或另一件风扇借值；本批没有绑定新的实时传感器。
