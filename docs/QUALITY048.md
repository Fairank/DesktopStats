# 0.48 整机完整性与可见性

对应源码候选 0.48.0-preview.1；以 0.47 独立冻结的源码、包和回归为历史基线，不覆盖旧证据。仍保持六版和 13 个历史保存值，本轮新增零售型号为零。目录仍为 828 个具名产品（514 本体＋314 可选），不是新增了 828 套独立 CAD。

本轮逐项问题与结构说明见[整机完整性复核](ASSEMBLY_COMPLETENESS048.md)，完整 29 组需求及未完成项见[需求账本](REQUIREMENTS.json)。

已实现并分别定向检查的范围：AIO 接头与软管连续性、三套明确主要配件参考、可切换内部检视，以及拥挤线稿中主要硬件完整轮廓的分配。最终 North XL r4 的六版整机主图及水冷关系图已逐张离屏审阅：两条 RAM、PSU、SSD、8 条已知线路和两条 RAM 静态灯区可观察；这不是全部接线、全灯效或原生验收。渲染开关不删除物理部件；未知本机内存不自动替成参考内存。全目录灯区、所有真实装机细节及 PCBS 级覆盖仍未完成。

## 已完成的专项验证

- AIO：42项检查通过，含27款本体一体水冷 × 三档细节的真实端环／接管轴向，以及已有风冷、模块化水冷和已选分体回归。24个同输入旧新几何桥只改变 AIO 既有软管网格，其他网格／元数据保持相同，实际三角形计数按变化更新。
- 内部检视：16项软件／Mock 定向检查通过，三角形、透明、线稿与拾取共用规则；窗口／桌面共享接线，切换不重建或上传场景。另做了独立只读流程复核，未发现不同步或清理缺陷；这不是原生 GL 运行验收。
- 参考预设：原三套主要配件、13个保存选项共享物理数组检查通过；AIO随后改为 North XL，最新新旧预设12项检查通过。已知线路与未收录前置 I/O 分开，不能称全部接线齐全。
- 线稿：26项检查通过，含最新 North XL 与更拥挤 HAF 的双 RAM／电源／GPU 固定圈与主叶／冷头端口与软管／主梁完整轮廓，以及原有水箱、管路和剪影合同。原有预期未改。10个独立范围 × 七种有边线选项，70份旧数据逐字节一致。初始失败原样保留；把所有主供电线强塞进核心会需要8872边，超过8192，因此最终采用硬件核心先于可选完整线束的分配。

- 机箱扇接线：最终源码新增 5 项定向检查通过，既有线缆／散热捕获和源码桥接保留。三套参考的已知线路分别为风冷 14、一体水冷 8、HAF 分体参考 8，出界／拒绝／省略均为零；AIO 前左及后左投影视角的原长斜跨线为零。只改机箱扇来源对应的参考入口／托盘路径，以及条件满足时未核柔性末端的朝向；固定插口、风扇实体、轴、叶片和安装位保持。原求解器、碰撞与迭代预算不变，默认独立风扇旧字节桥通过，任意未知组合仍可失败或提示待核。

这些专项有交叠，不能把数量相加冒称新的全量回归。North XL 与 HAF 前置 I/O 锚点仍未收录，8 条已知线路不等于全部接口已接通；参考路径也不承诺原厂线长或无延长线装配。

## 灯区与覆盖缺项

LFIII参考的8条已知线路仅包含主要供电和机箱扇线，未包含冷头一体PWM控制线；品牌专用灯控及集线器线路也未逐款补齐。水管端口验证与电气接线覆盖是不同项目。

两条 RGB RAM 展示的是已经接入的静态灯区，不是所有硬件的灯效验收。147 款显卡本体尚缺贯穿轮廓转换、三维几何与配色开关的灯区语义；主板 RGB／ARGB 插针、未亮 Q-LED、银色盖板和透明装饰片不能代替已核板载发光区域。21 款电源中 LOKI 的 `rgb_fan` 仍只驱动有色叶片，未接入灯区开关；THOR 空白 OLED 不是已绑定功率读数或 RGB。

独立 GPU 冷头仍为外观检视阶段：11 条有来源灯区不等于整卡灯光、图库逐型号熄灯控件、整机安装或连管已完成。没有新增真实设备灯控、逐 LED 时序、全局泛光或灯光采样。全品牌全系列、细部／扣具／接口、原生材质和 PCBS 1／2 级完整性仍保留缺项。

## 资源范围

最终 r4 参考包含 **356 个物理网格、101402 个三角形**，六版复用相同物理数组。r3 的 99122 与 r4 并非严格同源、同输入的对照，不从差值推算某一项修复增量或性能变化。没有新增采集器、线程或动画时钟，线稿沿用 8192 总边和既有每网格上限。

预算重分配会改变非空线稿批次数；渲染器对可见线稿 range 分别绘制，不能由总边不增推出总 GL drawcalls 不增。物理网格不因纯线条分配而新增，但这不等于整个版本所有绘制批次均保持不变。按既有线稿布局，8192 段的 float32 顶点／标签数据上限为 393216 字节（384 KiB）；它不包括实体网格、Python／Qt 对象、驱动／显存或整款进程。没有本轮整机 RSS、CPU、GPU 帧耗时或总 GL drawcalls 的同输入降幅实测。

LF III 240 标准档修接管增加96个三角形、6912字节 float32 顶点／法线数据（6.75 KiB），仍位于原软管网格；这不是整款程序的内存增量。其他代表 AIO 的相同档增量为9 KiB，未据此推算全部型号或进程占用。这是独立软管修复的同输入专项，不能与 r3／r4 整机三角形差值混算。

本页随对应源码和候选包冻结；构建、自检和源码发布发生在此快照之后，结果由同一分支的最终提交说明与交付记录报告。软件离屏图、Mock 绘制／拾取和候选包不代表 Windows 原生 GL、温度、磨砂或游戏中的实测验收。

游戏期间不安装、不重启 Stats、不提权、不显示测试窗。既有应用进程保持原样。
