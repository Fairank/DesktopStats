# 直接使用开源三维模型

本轮把已取得的 MIT 模型接入实际检视代码。开发源码提供“开源 3D”入口，能够读取下面三件参考、旋转缩放、点选部件、聚焦、隐藏和恢复，并切换原有六套风格。它们不再只用于生成说明图片。

**本机正在运行的 Stats 没有被替换。** 这些入口属于包含本次改动的新构建；游戏期间未安装、重启或显示原生测试窗。真实桌面上的原生画面与驱动占用还待验证。

## 下载与打开

1. 从[开源模型下载目录](https://github.com/Fairank/DesktopStats/tree/codex/open-model-references-v053/additional/pc-anatomy054)下载风冷或水冷 ZIP。通用风扇沿用[此前的 MIT 风扇包](https://github.com/Fairank/DesktopStats/blob/861420f4b2457cd2a661e99fd73cc4dd47349b20/additional/pc-anatomy053/DesktopStats-open-fan-reference053.zip)。
2. 在包含本次改动的版本中打开“硬件型号图鉴 → 开源 3D → 载入模型 ZIP…”。无需解压、导入原有型号库或修改硬件设置。
3. 拖动旋转、滚轮缩放；单击模型或从部件列表选择，按需开启“只看所选”或“隐藏所选”。关闭窗口后释放这件模型，再选下一件。

ZIP 是数据，不执行其中代码。这里只支持已经适配的参考包，不将任意网络 GLB、压缩扩展或材质格式假装为兼容。它也不是原有 JSON 型号 `.dspack` 的改名。

## 结构、风格和占用

- 六套风格保留为原版、可爱笑脸、彩色手绘、纯线条、奶油贴纸、拼色剪纸。颜色和线条策略复用现有系统；全部原始实体位置与表面保留。全局原有13个风格选项未删除。
- 开源参考保留部件层级和原作者的安装参考姿态。当前支持检视与隐藏，未给未知孔位、扣具动作或装配路线编造认证；也没有自动替换用户真实硬件。
- 只在手动选中一个包后读取、验证和生成这一个模型。启动和关闭图鉴不扫描或预载模型，不新增采样、后台计时器或自动旋转。切换风格复用同一份只读几何；切换模型先关闭旧窗口。
- 关闭时释放模型、Scene、Mesh和CPU缓冲；原生上下文丢失也走CPU引用清理。ZIP句柄在加载返回前已经关闭。
- 入口沿用顶部栏所选屏幕，选择器也绑定该屏幕；会在解析前和显示前检查屏幕及桌面状态。在别的屏幕玩全屏游戏时不会主动激活新检视；目标屏幕进入全屏时隐藏检视并关闭选择器。没有新增轮询器。

源模型没有可靠的本机转速绑定，因此这些独立参考暂时静止。旋转模型属于鼠标检视，不会把演示叶轮转动冒充实测RPM。

## 已完成的真实检查

适配器通过六项纯检查，并实际顺序加载了公开风扇 ZIP、风冷和水冷数据，再分别用最终两份 ZIP 加载。它们的精确身份、实体数量、部件、界限及只读几何均匹配。六版复用相同数组；每件用完后模型、Scene和全部Mesh引用释放。三件首次数据加载约0.025／0.072／0.162秒，仅是该机器上的读取与转换时间，不是帧率或整个软件占用。

风冷和水冷的四份叶片几何已逐份修正绕序与六个表面区域的法线。全部4,656个角点的法线方向正确；原始坐标字节、三角形表面、其他配件、实例、材质图与光源数据保持。两份修订后的模型都已实际生成同镜头软件图；黑色源材质仍偏暗，不能把法线修复称为整款外观完成。

检视窗口的纯源码检查覆盖旧装机路径保留、参考路径不调用整机生成器、静态交互、只读缓冲上传以及丢失上下文后的CPU清理。运行时测试覆盖目标屏幕、解析前后检查、切回游戏时不抢焦点、选择器接受后才解析以及过期回调。软件图鉴入口检查与原生驱动／真实窗口画面分别记录，不能互相替代。
