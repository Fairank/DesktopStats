# 直接使用开源三维模型

已取得的第三方模型接入实际检视代码。开发源码提供“开源 3D”入口，能够读取风扇、风冷、水冷、通用整机、CPU、RTX 3080、SSD和通用电源八件参考，旋转缩放、点选部件、聚焦、隐藏和恢复，并切换原有六套风格。它们不再只用于生成说明图片。

**本机正在运行的原版 Stats 没有被替换。** 新代码继续作为独立第二版：屏幕二的顶部栏、设置与顶部栏详情已经过有限原生验证，原版和前台保持不变；参考模型自身的原生驱动画面、真实磨砂与GPU占用仍待核。范围见 [055记录](DEVELOPMENT055.md)。

## 下载与打开

1. 从[全部已适配参考目录](https://github.com/Fairank/DesktopStats/tree/codex/open-model-references-v053/additional)选择单件 ZIP；[散热目录](https://github.com/Fairank/DesktopStats/tree/codex/open-model-references-v053/additional/pc-anatomy054)、[整机目录](https://github.com/Fairank/DesktopStats/tree/codex/open-model-references-v053/additional/whole-pc054)、[CPU／GPU目录](https://github.com/Fairank/DesktopStats/tree/codex/open-model-references-v053/additional/ccby-components054)与[SSD／电源目录](https://github.com/Fairank/DesktopStats/tree/codex/open-model-references-v053/additional/ccby-components055)分别下载。通用风扇沿用[此前的 MIT 风扇包](https://github.com/Fairank/DesktopStats/blob/861420f4b2457cd2a661e99fd73cc4dd47349b20/additional/pc-anatomy053/DesktopStats-open-fan-reference053.zip)。
2. 在包含本次改动的版本中打开“硬件型号图鉴 → 开源 3D → 载入模型 ZIP…”。无需解压、导入原有型号库或修改硬件设置。
3. 拖动旋转、滚轮缩放；单击模型或从部件列表选择，按需开启“只看所选”或“隐藏所选”。关闭窗口后释放这件模型，再选下一件。

ZIP 是数据，不执行其中代码。这里只支持已经适配的参考包，不将任意网络 GLB、压缩扩展或材质格式假装为兼容。它也不是原有 JSON 型号 `.dspack` 的改名。

这些包当前通过独立三维检视打开。CPU／GPU小组件的逐型号外形，以及把参考转换成固定安装位可互换的装配件，仍需要继续适配与验收。

## 结构、风格和占用

- 六套风格保留为原版、可爱笑脸、彩色手绘、纯线条、奶油贴纸、拼色剪纸。颜色和线条策略复用现有系统；全部原始实体位置与表面保留。全局原有13个风格选项未删除。
- 开源参考保留部件层级和原作者的安装参考姿态。当前支持检视与隐藏，未给未知孔位、扣具动作或装配路线编造认证；也没有自动替换用户真实硬件。
- 只在手动选中一个包后读取、验证和生成这一个模型。启动和关闭图鉴不扫描或预载模型，不新增采样、后台计时器或自动旋转。切换风格复用同一份只读几何；切换模型先关闭旧窗口。
- 关闭时释放模型、Scene、Mesh和CPU缓冲；原生上下文丢失也走CPU引用清理。ZIP句柄在加载返回前已经关闭。
- 入口沿用顶部栏所选屏幕，选择器也绑定该屏幕；会在解析前和显示前检查屏幕及桌面状态。在别的屏幕玩全屏游戏时不会主动激活新检视；目标屏幕进入全屏时隐藏检视并关闭选择器。没有新增轮询器。

源模型没有可靠的本机转速绑定，因此这些独立参考暂时静止。旋转模型属于鼠标检视，不会把演示叶轮转动冒充实测RPM。

## 已完成的真实检查

适配器通过六项纯检查，并实际顺序加载了公开风扇 ZIP、风冷和水冷数据，再分别用最终两份 ZIP 加载。它们的精确身份、实体数量、部件、界限及只读几何均匹配。六版复用相同数组；每件用完后模型、Scene和全部Mesh引用释放。三件首次数据加载约0.025／0.072／0.162秒，仅是该机器上的读取与转换时间，不是帧率或整个软件占用。

风冷和水冷的四份叶片几何已逐份修正绕序与六个表面区域的法线。全部4,656个角点的法线方向正确；原始坐标字节、三角形表面、其他配件、实例、材质图与光源数据保持。两份修订后的模型都已实际生成同镜头软件图；黑色源材质仍偏暗，不能把法线修复称为整款外观完成。

检视窗口的纯源码检查覆盖旧装机路径保留、参考路径不调用整机生成器、静态交互、只读缓冲上传以及丢失上下文后的CPU清理。运行时测试覆盖目标屏幕、解析前后检查、切回游戏时不抢焦点、选择器接受后才解析以及过期回调。软件图鉴入口检查与原生驱动／真实窗口画面分别记录，不能互相替代。

整机另有四项新检查通过，覆盖延迟分派、固定来源核验、解码器许可哈希与冷导入不读取文件。最终ZIP实际通过公开`load_reference`入口，67个Mesh的25部件、33,383三角形和2,403,576B缓冲匹配；六版共用同一几何所有者，返回前ZIP关闭，使用后模型／Scene／全部Mesh引用释放。该次读取约0.075秒墙钟、0.078秒CPU，不等同于帧率或整款程序负担。

CPU／GPU新增六项控制分别有通过证据：首批五项，之后新增一个Windows目录大小写优先级控制；原五项方法保持相同，没有冒称一次六项重跑。先检测原有散热器／风扇身份，再检测CC BY参考，避免解压后的`REFERENCE054.json`被Windows当成新`reference054.json`。最终两份CPU／GPU ZIP在修复后的公共入口实际读取，分别保留426／56,742三角形、2／27部件；六版共用只读缓冲，ZIP在模型使用前关闭，全部模型／Scene／Mesh引用释放。最后一批新控制加两份ZIP读取合计约0.103秒墙钟、0.094秒CPU，无图片解码、原生渲染或真实硬件访问。

四风扇折线修正新增五项控制，覆盖被平滑顶点法线掩盖的真实直角、平面焊接不产生假对角线、退化面与很小有效面的区分、型号／部件／风格作用域。公开代码生成的67个网格身份与98,004个边线浮点值，和已看图候选逐字节相同，仍为8,167段，原35°阈值、每网格512／整景8192段上限保持；PN位置／着色法线与全部视图身份不变。旧模型六版样例的缓冲字节相同，模型引用释放通过。约0.499秒墙钟／0.469秒CPU是这批局部验证，不是程序日常占用。

更新六图按公开`edge_batches`准备线条：原版无边线复用原帧，纯线条复用已看图新帧，仅其他四版因输入改为公共规则而重新渲染。六版源几何和配色头字节一致，新增四次CPU软件光栅化，无新ZIP或PN导出。该批约1.475秒墙钟，四个顺序渲染辅助进程各约0.081–0.088秒／35.2MB峰值；这些是短时软件出图进程，不能当作Stats的常驻或原生驱动内存。
