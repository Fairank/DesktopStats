# 按需硬件扩展包

DesktopStats 0.36 将硬件渲染器与新增型号数据分开。原有硬件目录保留在本体；首批新增 CPU 按 Intel、AMD 分成两个可独立下载、导入和移除的 `.dspack` 文件。它们共用全部 13 套外观，不为每套风格复制一份目录或网格。

在「整机视图 → 硬件扩展包」进入 GitHub 下载，随后选择「导入扩展包」。安装后型号直接进入参考 CPU 选择器，已确认的系统名称也可匹配这些型号。移除后保留原设置中的型号 ID；该型号不可用时回到检测到的硬件并提示，不影响温度等硬件采集，也不会把本机实时读数绑定给手动选择的参考型号。

首版扩展包格式只支持 CPU。机箱、主板、显卡、内存、散热、电源、存储和扩展卡的现有目录仍在基础程序；后续类别需要独立的数据校验和绘制适配，不能把任意文件改成此后缀就导入。目录是逐产品核实的原创比例示意，尚未覆盖市场全部产品，也未声称达到装机模拟器的完整度。软件不包含或复制装机模拟器的素材。

## 占用控制

- 导入模块时不读文件；需要扩展型号或打开扩展包列表时才初始化目录。
- 只保留型号索引，以及最多 8 个已选型号的轻量描述；未安装的 CPU 大目录不被程序导入。
- 三维模型仍只按当前选择生成。包系统不持有三维网格、贴图或渲染上下文；原有整机视图保留一个场景缓存，关闭后释放。
- 不创建后台线程、定时目录扫描、联网检查、额外传感器采集或服务。下载由用户主动进入 GitHub 完成。
- 单包最多 256 型号、1.5 MiB 压缩文件；一个配置最多 16 包、合计 1,024 可选型号。超过限制会拒绝，不提高现有三维几何和线条预算。

包文件体积和模型准备耗时不等于整个 Stats 的驻留内存或 CPU 占用；整机占用需要在实际运行版本另测。

## 文件和来源

包是仅含 `manifest.json` 与 `models.json` 的 ZIP。程序不解压、不加载脚本、不下载来源链接中的文件。校验覆盖成员名、数量、大小、JSON 重复字段、有限数值、CPU 封装生成器白名单、型号冲突、清单一致性和内容 SHA-256。内容哈希用于检查一致性，不是数字签名或发布者认证；请从项目自己的 GitHub 发布页获取。

清单包含完整的 PolyForm Noncommercial 1.0.0 许可和原创数据声明。原创建模数据禁止商业使用；产品名称、商标仍归各自权利人。原有第三方组件的许可保持独立，见仓库的 `LICENSING.md` 和 `NOTICE`。

CPU 型号可以共享同一种物理封装。资料未确认的外形尺寸保持 `null`，绘图使用明确标注的系列参考轮廓；触点分布与盖板厚度始终是示意，不能用作电气针脚图、制造图或装机适配保证。CPU 目录不推断散热器、风扇数量或测速通道。

## 可复现导出

从源码环境运行 `python tools/export_hardware_packs.py`，在 `dist/hardware-packs` 生成两个数据包与 `hardware-packs-index.json`，包含实际体积、校验值、产品数量和最低软件版本。相同数据会生成相同字节。广泛的作者目录位于 `cpu_catalog.py`，正常运行程序不导入此目录。
