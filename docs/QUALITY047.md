# 0.47 细节与加载改进

本轮为开发中的源码候选。0.46 已保留为独立分支及不可覆盖的数据包；本轮不能用它的回归结果为变化后的代码验收。

固定六版：1 原版、2 可爱笑脸、3 彩色手绘、4 纯线条、5 奶油贴纸、6 拼色剪纸。原版不加笑脸。其余旧保存选项保留。现有缺口完善前不增加外观。

## 本轮核对范围

- 六款既有主板：ASRock Z790 PG-ITX/TB4、B650I Lightning WiFi、X670E Taichi、B650E Steel Legend WiFi、B650M PG Riptide WiFi，以及 GIGABYTE Z790 AORUS MASTER rev.1.0。按各自官方照片细化装甲、M.2 盖板和静态材质；不将齿轮装饰画成风扇，不猜隐藏的叶型、孔位或电路。
- 显卡零售水冷头：将已核来源的产品做成独立可选参考模型。具体 PCB 修订、端子配置、总装包络与本体尺寸分别保存；未知的 GPU 芯片／显存／螺孔位置不补造，未经证实的整卡替换和装机连管不开放。
- 零件图库：复杂图形在可见时按需生成，关闭及快速切换会取消或丢弃旧结果；只保留有限缓存。图形工作不使用硬件采样线程，不增加采样或动画时钟。
- CPU／GPU 小组件：沿用现有真实组件与六版型号轮廓，继续检查静止外壳、已核叶片、未知结构和渲染资源边界。

## 仍未完成

完整市售品牌与系列、20 款显卡叶型资料、全部实物装配间隙、任意水路连接图、硬管内联与外围设备等继续列在 [全文需求账本](REQUIREMENTS.json) 和 [与装机模拟器的差距](PCBS_GAP_ANALYSIS.md)。新增目录不能替代几何或安装验证。

当前用户仍在游戏：本轮不安装、不重启 Stats、不提权、不显示测试窗。CPU 温度重启恢复、三个真实窗口的磨砂、屏幕二、游戏隐藏及整款程序资源占用继续待原生验收；离屏图、候选包和局部测量均不能给这些项目打勾。

## 回归结果与修复记录

246 个测试模块的最新通过记录合并为 **3,225 项，保留 1 项原跳过**。这不是最终字节上的一轮全绿：首轮 3,210 项有 7 个失败模块；修复后对受影响的 18 模块定向复测 **188／188 通过**，最终 543 个代码文件与稳定的最后自检围栏一致。

- 两个离线导出不再导入用户扩展包／配置模块，完整图集及许可校验通过；旧蓝墨选项标签也与程序对齐，不编号为第七版。
- 已核实的 Master 主板不再应显示待核。旧测试改用分离的待核夹具，仍检查真实选择器和详情提示，另确认真实已核记录没有待核提示。
- 0.39 静态记录基线继续保持原哈希；测试读取静态风扇记录，0.44 的安装来源叠加仍由其独立回归检查，没有把期望哈希换成当前值。
- 未打开图库的扩展包更新测试补齐新增生命周期夹具，保留禁止加载图库的断言。
- 安装事务的私有文件夹在首轮遇到 3 次 Windows 拒绝改名，原失败保留；未改生产或加入重试，独立串行复跑 62／62 通过。全过程没有操作真实安装。
- 自检补齐空 GPU 类别，并增加第 18 项：从随附真实 12 款 GPU 数据包验证私有安装、实际网格和 SVG、兼容限制、移除及零缓存；没有导入作者库、启动原生桌面或采样硬件。
